# Каталог газов — лабораторная 6

React + TypeScript + Redux Toolkit + Axios. Данные API соответствуют соседнему проекту `../labs_backend` (FastAPI).

## Запуск

```bash
npm ci
npm run dev
```

Бэкенд: `http://127.0.0.1:8000`, MinIO: `http://127.0.0.1:9000`. Для других адресов скопируйте `.env.example` в `.env.local`. В браузере используйте один и тот же hostname при входе и просмотре приложения.

```bash
npm run build
npm run lint
npm test
```

## Три части

1. Redux Toolkit: фильтр названия в `src/store/gasesSlice.ts`, типизированные hooks/store в `src/store/index.ts`; API-запросы каталога и ленты, mock-fallback только для гостя при сетевой ошибке или HTTP 5xx. Ошибки 4xx не подменяются mock. Поиск по названию соответствует серверному параметру `search`.
2. Авторизация: `#/login`, вручную написанный Axios в `src/api/auth.ts`, синхронные auth-actions без thunk и кодогенерации. `#/create`: создание черновика с двумя файлами, загрузка существующего черновика, публикация с массой и плотностью, удаление черновика. Лайки в плитке и ленте; удаление опубликованных газов только при `is_owner === 1`.
3. Сгенерированный Axios-клиент в `src/api/generated/Api.ts`, газовые `createAsyncThunk`, proxy API/MinIO, обработка ошибок, блокирующий индикатор запросов; материалы защиты в `docs`.

В приложении ровно четыре страницы: плитка `#/catalog`, лента `#/feed`, вход `#/login`, добавление `#/create`. Навигация выполняется без перезагрузки. Фильтр сохраняется при переходах между страницами и сбрасывается при выходе. Поиск применяется кнопкой «Найти» или Enter; ввод текста сам по себе не отправляет запросов, таймера нет. При открытии каталога и смене пользователя данные загружаются автоматически.

Нижняя панель видна и во время загрузки. Пункт «Добавление» заблокирован для гостя, а во время запросов блокируются все пункты. Прямое открытие `#/create` гостем показывает предложение войти; thunk также проверяет наличие пользователя.

Redux содержит `auth.user/status/error` и `gases.search/items/feed/draft/source/pending/error/catalogRequest`. Статусы авторизации: `idle`, `loading`, `authenticated`, `error`; жизненный цикл thunk: `pending`, `fulfilled`, `rejected`. `configureStore` включает thunk middleware и Redux DevTools. Устаревший ответ поиска не заменяет более свежий.

Redux не сохраняется в localStorage. После F5 пользователь в интерфейсе — гость, а HttpOnly `session_id` остаётся в cookie до выхода или истечения срока. Cookie по-прежнему может аутентифицировать серверный запрос; гостевой интерфейс скрывает действия пользователя и признаки владения. Это два разных состояния, как требуется для демонстрации. Не пытайтесь читать HttpOnly cookie JavaScript-кодом.

## OpenAPI и кодогенерация

`docs/openapi.json` экспортирован из `app.openapi()` соседнего FastAPI-проекта. Повторная генерация из сохранённой схемы работает без запущенного бэкенда:

```bash
npm run api:generate
```

Для обновления схемы из работающего сервиса:

```bash
npm run api:update
```

Можно задать `OPENAPI_URL`. Генератор `swagger-typescript-api` работает с `httpClientType: 'axios'`; hook исключает маршруты вне `/api/gases`. Сгенерированный файл не редактируется вручную. Все обращения к газовому домену выполняются через него в thunk, названных по теме: `fetchGases`, `fetchGasFeed`, `fetchGasDraft`, `createGas`, `publishGas`, `deleteGas`, `toggleGasLike`.

## Proxy и медиа

Vite и preview проксируют `/api/*` в FastAPI, `/s3/*` в MinIO с удалением `/s3`, `/backend/static/*` в FastAPI с удалением `/backend`. Браузер обращается к своему origin, поэтому отдельный CORS-доступ к API и S3 ему не нужен. При размещении production-сборки эти же маршруты нужно настроить в обратном прокси хостинга: конфигурация Vite не входит в статические файлы `dist`.

`src/api/media.ts` преобразует адреса MinIO с портом 9000 или bucket-путём `/gas-media/` в `/s3/...`, сохраняя имена объектов и query string. Старые серверные `/static/img/...` идут через `/backend`. Пустые медиа заменяются локальными `/media/default-gas.png` и `/media/default-gas-video.mp4`. Реальные новые загрузки должны возвращать адреса MinIO; прокси не выдаёт локальные файлы за S3.

## Ограничения существующего бэкенда

Создание принимает только название и файлы, публикация — массу и плотность. Поля формулы и описания сервером при этих операциях не заполняются, поэтому форма их не обещает. `GasListItem` не содержит `is_liked`: перед переключением лайка thunk получает актуальное значение из `/api/gases/feed?gas_id=...`. Схема ленты не возвращает изображение и владение, поэтому удаление опубликованных газов доступно в плитке. Для загрузок MinIO нужны работающий сервис и настроенная политика чтения bucket.
