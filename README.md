# Каталог газов

Лабораторная работа №5: базовое SPA для просмотра каталога газов
и их молярных масс.

## Технологии

- React
- TypeScript
- Vite
- React-Bootstrap и Bootstrap

Данные берутся только из локальной mock-коллекции.
Подключение к бэкенду в текущей версии не используется.
Redux и Context не используются.

## Запуск

Требуется установленный Node.js с npm.

```bash
npm install
npm run dev
```

Адрес сервера разработки выводится в терминале.

## Сборка

```bash
npm run build
```

Команда проверяет TypeScript и создаёт сборку в папке dist.

Для локального просмотра сборки:

```bash
npm run preview
```

## Страницы приложения

### Каталог — #/catalog

Отображает газы в виде плитки из двух колонок.

Поле поиска фильтрует коллекцию по названию или химической формуле
без учёта регистра. Пробелы по краям запроса игнорируются.
При пустом запросе отображаются все газы.
Если совпадений нет, выводится сообщение «Газы не найдены».

Карточка содержит:
- изображение;
- название и краткое описание;
- молярную массу в г/моль;
- кнопку «Подробнее»;
- количество лайков внутри кружка с сердцем.

«Подробнее» открывает страницу выбранного газа.
Для гостя изменение лайков и удаление газов не предусмотрены.

### Лента — #/feed

Показывает один газ на фоне автоматически воспроизводимого видео.
Видео повторяется и воспроизводится без звука.

На странице отображаются:
- название и химическая формула;
- молярная масса в г/моль;
- плотность при нормальных условиях в кг/м³;
- количество лайков;
- ссылка «Подробнее»;
- кнопка со значком › для перехода к следующему газу.

После последнего газа снова показывается первый.

### Подробности газа — #/gas/:id

Отображает изображение, описание, формулу, молярную массу,
плотность, количество лайков и видео выбранного газа.

Ссылка «← Каталог» возвращает к плитке.
У видео доступны стандартные элементы управления браузера.

Если газа с указанным идентификатором нет, выводится сообщение
«Газ не найден» и ссылка возврата в каталог.

## Нижняя навигация

Панель содержит четыре пункта:
- «Лента» — доступен;
- «Добавление» — недоступен;
- «Плитка» — доступен;
- «Вход» — недоступен.

Приложение реализует интерфейс гостя.
Переходы между страницами выполняются без перезагрузки документа.

## Mock-данные

Коллекция расположена в src/mocks/gases.ts.
Тип объекта описан в src/types/gas.ts.

Поля объекта:
- id — идентификатор;
- gas_name — название;
- gas_formula — химическая формула;
- short_description — краткое описание;
- gas_image_url — адрес изображения или null;
- gas_video_url — адрес видео или null;
- molar_mass — молярная масса, г/моль;
- density_normal_conditions — плотность при н.у., кг/м³;
- likes_count — количество лайков;
- is_owner — признак владельца, для гостя равен 0.

## Медиа по умолчанию

Изображения и видео находятся внутри проекта в public/media.

Если адрес медиа равен null, пустой строке или строке из пробелов,
используются:
- /media/default-gas.png;
- /media/default-gas-video.mp4.

У кислорода в mock-коллекции оба адреса равны null,
чтобы продемонстрировать подстановку медиа по умолчанию.

## Компоненты и props

- GasCard получает gas и отображает карточку.
- GasFilter получает search и onSearchChange.
- GasVideo получает gas, className и controls.
- BottomNav получает path для выделения активного пункта.
- GasDetailsPage получает gasId для выбора газа.

## Используемые хуки

useState:
- хранит поисковую строку в CatalogPage;
- хранит индекс текущего газа в FeedPage;
- хранит текущий путь в App.

useEffect:
- подключает обработчик события hashchange в App;
- возвращает функцию очистки, удаляющую обработчик.

## Маршрутизация

Маршрут хранится в части адреса после символа #.
App отслеживает событие hashchange и выбирает компонент страницы.

Используются стандартные API браузера, без библиотеки маршрутизации.
Кнопки браузера «Назад» и «Вперёд» поддерживаются.

## Проверка через Network

При открытии приложения браузер загружает файлы приложения
и локальные медиа.

Запросов к /api/gases нет: объекты газов импортируются
непосредственно из mock-коллекции.

Фильтрация выполняется в браузере и не отправляет запросов на сервер.
