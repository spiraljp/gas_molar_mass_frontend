# Gas Molar Mass Frontend

Репозиторий фронтенда для курсового проекта по дисциплине Web.

## Тема

Расчет молярной массы газа.

## Предметная область

Приложение представляет собой заявочную систему для расчета молярной массы газа.

Услуги — это различные газы с известными молярными массами и физическими свойствами.

Заявка — это расчет молярной массы неизвестного газа по данным о его массе и объеме при нормальных условиях. Также в заявке может указываться смесь из двух выбранных газов с заданными концентрациями.

## Планируемый стек

- React
- Redux

- React-Bootstrap

## Лабораторная работа 1

В рамках первой лабораторной работы разрабатывается дизайн интерфейса приложения.

Дизайн выполняется в Figma в портретном мобильном режиме и состоит из трех страниц:

- Лента
- Добавление
- Плитка карточек

На всех страницах располагается нижняя панель навигации с тремя вкладками.

## Дизайн-референс

В качестве дизайн-референса выбран сервис PubChem:

https://pubchem.ncbi.nlm.nih.gov/

Из референса используются:

- светлая научно-справочная стилистика;
- голубая цветовая тема;
- карточки со свойствами вещества;
- акцент на химической формуле, молярной массе и физических характеристиках газа.

Основные цвета:

- `#005EA2`;
- `#E5FAFF`;
- `#162E51`.
